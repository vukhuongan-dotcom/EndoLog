# Icons

Icon nét 24 × 24, stroke 2, đầu và góc tròn. Mực mặc định `text-main` #26292F; trong ứng dụng nhúng inline và dùng `stroke="currentColor"` để nhận màu tab, nút, pill. Không emoji ở bất kỳ đâu trong giao diện.

- `log.svg` — tab Nhật ký ca soi.
- `calendar.svg` — tab Hẹn soi lại; pill "Đến hạn soi lại", "Theo dõi 14–30 ngày".
- `quality.svg` — tab Chỉ số chất lượng.
- `alert.svg` — pill cảnh báo hội chẩn Ngoại khoa, biến cố.
- `check.svg` — pill "Không biến cố / hoàn tất", "Đạt chuẩn".
- `clock.svg` — pill "Chờ GPB".
- `export.svg` — Xuất dữ liệu.
- `add.svg` — Thêm ca soi.
- `moon.svg`, `sun.svg` — chuyển nền tối / nền sáng.
- `logout.svg` — Đăng xuất. `user.svg` — tài khoản.
