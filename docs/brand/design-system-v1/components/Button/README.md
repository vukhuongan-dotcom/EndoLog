# Button

Nút bấm cao tối thiểu 44 px; mỗi màn hình chỉ một nút chính.

- **Chính** `el-btn--primary`: nền `primary-fill`, chữ `on-primary`. Hành động chính của màn hình: Thêm ca soi, Lưu, Nhập kết quả GPB.
- **Phụ** `el-btn--secondary`: nền `bg-card`, viền `border-strong`, chữ `text-main`. Xuất dữ liệu, Huỷ, Lọc.
- **Nhẹ** `el-btn--ghost`: chữ `primary`, không viền. Liên kết trong thẻ.
- Icon 18 px bên trái, cùng màu chữ. Nhãn là động từ + danh từ, viết hoa đầu câu.
- Focus: viền `focus-ring` 2 px cách 2 px. Vô hiệu: độ mờ 45 %.
- Không dùng `primary` làm nền nút ở nền tối.
