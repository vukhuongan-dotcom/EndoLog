# Logo

Bộ ghép biểu tượng + wordmark + dòng phụ, dùng ở màn hình đăng nhập và header máy tính.

- Biểu tượng 40 px (`mark-desktop`), wordmark Plus Jakarta Sans 800: "Endo" `text-heading`, "Log" `primary`. Dòng phụ `caption` không in hoa, `text-muted`.
- Header điện thoại: biểu tượng 28 px không quầng sáng (`endolog-mark-small.svg`) + "EndoLog", không dòng phụ.
- Biểu tượng dùng tệp trong nhóm Logos hoặc SVG inline với nét `var(--primary)` và chấm `var(--accent-light)` để tự đổi theo nền.
- Không: thêm tên bệnh viện vào cụm logo, gradient, bóng, đặt wordmark thành ảnh.
