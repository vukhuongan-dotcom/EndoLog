# NavTab

Ba tab chính của EndoLog; trên điện thoại cùng ba mục ở thanh dưới.

- Mục đang mở có đủ 3 dấu: chữ `primary` đậm 600, gạch dưới 2 px `primary`, chấm 5 px `accent-light`. Không bớt dấu nào.
- Mục khác: chữ `text-muted` 500, icon cùng màu.
- Một dòng, không xuống hàng; vùng chạm ≥ 44 px. Đặt `aria-current="page"` cho mục đang mở.
- Thứ tự cố định: Nhật ký ca soi · Hẹn soi lại · Chỉ số chất lượng.
