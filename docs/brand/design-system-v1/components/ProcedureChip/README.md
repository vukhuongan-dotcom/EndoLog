# ProcedureChip

Chip loại thủ thuật đặt đầu mỗi thẻ ca, dòng bảng và thẻ chỉ số.

- Nền `proc-*-tint`, chữ `proc-*-text` 700 12 px giãn .04em, chấm 7 px `proc-*`. Bo `radius-sm`.
- Luôn ghi mã: EGD, COL, ERCP. Tên đầy đủ (Dạ dày, Đại trực tràng, Mật tụy ngược dòng) dùng ở bộ lọc: "COL · Đại trực tràng".
- Mã ca (`COL-2026-0142`) đứng cạnh chip, chữ `text-main`, không tô màu thủ thuật.
- Không dùng màu thủ thuật cho trạng thái hay cho nút.
