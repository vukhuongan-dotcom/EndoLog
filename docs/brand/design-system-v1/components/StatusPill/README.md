# StatusPill

Pill trạng thái lâm sàng của một ca hoặc một chỉ số.

- Viền và chữ cùng màu `clinical-*`, nền `bg-card`, bo `radius-pill`, chữ 600 13 px, icon 15 px.
- Năm trạng thái và icon cố định: urgent + alert · pending + clock · due + calendar · ned + check · neutral + clock.
- Luôn có chữ; màu chỉ để quét nhanh. Tối đa một pill trên đầu thẻ ca (trạng thái nặng nhất).
- Chữ tiếng Việt: "Viêm tụy sau ERCP mức nhẹ · AGREE II", không "PEP MILD".
